## django-stateless-mcp 0.1.8

No changes to the installed package — this release versions the repository's
documentation.

### Added

- **An elicitation recipe: forms and destructive-action confirmations.**
  `docs/recipes/elicitation-forms-and-confirmations.md` gives the package's
  headline feature its worked example: a `delete_customer` tool that elicits a
  boolean confirmation before the ORM delete (paired with `destructive_hint` —
  hints for the client, elicitation as the enforcement), and a
  `create_customer` tool whose validation lives in a Django `ModelForm`, with
  corrections elicited for exactly the fields the form rejects, quoting
  Django's own error messages. The recipe's constructor calls and the
  form-errors → elicitation → merged-retry flow were executed against the
  installed SDK before landing. (ADR-0036)

### Changed

- **Every surface links the spec.** "2026-07-28" links to the MCP
  specification at first mention on the README and each docs page, and
  `why-stateless.md`'s SEP table links SEP-2567, SEP-2575, and SEP-2322 to
  their canonical documents in the spec repository. (ADR-0035)
- **ADR citations are gone from user-facing docs.** All eleven links into
  `docs/adr/` from the docs site, README, and example README were removed —
  each was a trailing citation on prose that already states the reason.
  Contributor surfaces (ARCHITECTURE.md, CONTRIBUTING.md) keep theirs.
  (ADR-0035)
- **`usage.md` sheds explanation that had leaked into how-to material.** The
  CSRF and `ATOMIC_REQUESTS` exemption rationale is one sentence each, the
  hint-by-hint `ToolAnnotations` gloss defers to the linked spec schema, and
  the payload-size note moves out of "Mount path" into its own section.
  (ADR-0035)
- **Cookiecutter boilerplate is cut.** `installation.md` loses its
  clone-and-tarball "From source" recipe (contributors are pointed at
  CONTRIBUTING.md); CONTRIBUTING.md loses its generic "Types of
  Contributions" section and its wrong "Python 3.12, 3.13, 3.14" support
  claim (the floor is 3.10). (ADR-0035)
- **The README survives PyPI rendering.** Its two relative links (example
  README, ARCHITECTURE.md) are now absolute GitHub URLs — PyPI resolves
  relative hrefs against pypi.org, so both were broken on the project page.
  The "Why use this" section also converges on the docs home page's
  bullet-per-benefit form, and the elicitation bullet regains the explicit
  "confirmation before an update or delete" wording, linking the new recipe.
  (ADR-0035, ADR-0036)
- **The example walkthrough was re-verified end to end** — fresh Inspector
  install via npx, the Playwright-driven quick start, the admin permission
  cycle, and every curl proof (cross-instance resume, kill-the-fleet resume,
  tampered state, subscription stream). One real defect surfaced and is
  fixed: in the permissions walkthrough, the first server must be
  disconnected *before* the new card's **Settings** can be opened — a
  connected server greys out every other card's buttons, and the old step
  order hit a dead button.

### Infrastructure

- The GitHub repository now carries the docs site as its homepage and
  discovery topics (`django`, `mcp`, `model-context-protocol`, `ai`, `llm`,
  `python`); the unused wiki is disabled so documentation has a single home.
