# Installation

## Stable release

To install django-stateless-mcp, run this command in your terminal:

```sh
uv add django-stateless-mcp
```

Or if you prefer to use `pip`:

```sh
pip install django-stateless-mcp
```

## From source

The source files for django-stateless-mcp can be downloaded from the [Github repo](https://github.com/Streamlined-Analytics/django-stateless-mcp).

You can either clone the public repository:

```sh
git clone https://github.com/Streamlined-Analytics/django-stateless-mcp
```

Or download the [tarball](https://github.com/Streamlined-Analytics/django-stateless-mcp/tarball/main):

```sh
curl -OJL https://github.com/Streamlined-Analytics/django-stateless-mcp/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd django-stateless-mcp
uv sync
```
