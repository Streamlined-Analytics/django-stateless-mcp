## django-stateless-mcp 0.1.11

Two small fixes surfaced by driving test coverage to 100%, plus a refreshed
development toolchain. No public API moves, and the package's runtime
dependencies (`django>=5.2`, `mcp>=2,<3`) are unchanged.

### Fixed

- **`subscriptions/listen` leaked a stream when the client disconnected
  early.** Only the success path handed the internal message stream to the
  streaming response; the two error exits — the SDK handler ending without a
  response, and the request being cancelled before the first frame (a client
  gone before the stream starts) — dropped it unclosed, firing anyio's
  `ResourceWarning` from `__del__`. Both exits now close the stream. Present
  since the subscriptions feature landed. (ADR-0042)
- **`PermittedToolsFilter` crashed on a `tools/list` result without a
  `tools` key.** A dict-shaped result missing the key raised `KeyError`,
  where the model-shaped branch already passed it through untouched. The
  filter now treats both shapes the same. Not reachable with the current SDK,
  which always sets the key. (ADR-0042)

### Changed

- Test coverage is measured across every supported interpreter, Django line,
  and the out-of-process multi-worker fleet, and gated at 100% in CI — the
  gate itself is what surfaced both fixes above. The SEP-2322 fixture flows
  (sampling, roots, multi-round `requestState`, capability gating,
  `prompts/get`) are now regression-tested by pytest as well as the MCP
  conformance harness. (ADR-0041, ADR-0042)
- Development toolchain refreshed: coverage 7.15.4, ruff 0.16.4,
  pytest-django 4.14.0, django-stubs 6.1.0 (the first Django 6.1 stubs), and
  updated GitHub Actions pins including the re-actors/alls-green 1.3.0
  security fix (GHSA-gj76-h2ch-5m76).
