## django-stateless-mcp 0.1.10

A forward-compatibility release for the in-development Django 6.2. Nothing
changes on Django 5.2, 6.0, or 6.1, and no public API moves.

### Fixed

- **Django 6.2 silently disabled the `ATOMIC_REQUESTS` exemption.** Django
  [#29303](https://code.djangoproject.com/ticket/29303) changed
  `transaction.non_atomic_requests()` to return a new wrapper instead of
  mutating the view in place. `mcp_view()` called it for its side effect and
  discarded the result, so from 6.2 the exemption landed on a wrapper that was
  thrown away and every request under `ATOMIC_REQUESTS = True` — the
  cookiecutter-django default — raised `RuntimeError: You cannot use
  ATOMIC_REQUESTS with async views.` again, exactly as it did before 0.1.6.
  The view now keeps the wrapper Django returns, and re-marks it with
  asgiref's `markcoroutinefunction` so Django's plain-`def` wrapper cannot
  demote the async view to a sync one. Released Django lines were never
  affected. (ADR-0039)
