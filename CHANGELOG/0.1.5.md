## django-stateless-mcp 0.1.5

No changes to the installed package — this release versions the repository's
example project and documentation.

### Added

- **The example project boots with `docker compose up`.** A root `Dockerfile`
  and `compose.yaml` run the same four-worker uvicorn fleet as `just demo-asgi`
  with no local uv, Python, or just required. The image installs from `uv.lock`
  (preserving the supply-chain quarantine), and the compose service bind-mounts
  `example/` so the README's host-run permission walkthrough reaches the
  containerized fleet through the shared SQLite database. `just demo-docker`
  rebuilds and boots it. (ADR-0022)

### Changed

- **ADRs are no longer published on Read the Docs.** The decision records are
  contributor-facing history and now live only in the repository's `docs/adr/`;
  the docs site links to the GitHub tree instead. (ADR-0023)
- The example README sets expectations for the subscription-stream demo under
  multiple workers: the in-memory bus is per-process, so the trigger lottery is
  worse than uniform — run a single worker for a deterministic demo.
